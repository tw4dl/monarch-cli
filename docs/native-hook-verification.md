# Native hook verification

## Codex

The real host loaded both registered events without parsing errors. Following
native trust review, SessionStart context reached the agent and Stop captured
metadata matching the actual session identity. No trust record was modified by
the verification. A subsequent native capture verified the installed counter fix.

The transcript parser counts Codex `function_call` and `custom_tool_call`, and
Claude `tool_use` records, while excluding output records. A failing-then-passing
regression covers the custom-call case and confirms arguments are not retained.
Counts cover a bounded tail and are explicitly partial for larger transcripts.
Working-tree snapshots describe current state, not a claim about session-only edits.

```bash
MONARCH_NATIVE_HOOK_TESTS=1 uv run pytest tests/axi/test_codex_native.py -q
```

The opt-in test starts a real app server with isolated configuration and checks
its native schema and trust-state parsing. It starts no model turn.

## Claude

The [official hook reference](https://code.claude.com/docs/en/hooks) defines
SessionStart stdout context and SessionEnd input with `cwd`, `session_id`,
`transcript_path`, and `hook_event_name`.

A temporary official Claude 2.1.330 runtime was verified against its npm SHA-512
integrity value. The real CLI consumed configuration generated by `install_hooks`
in isolated profiles. A loopback model stub returned a fixed answer, and the
Monarch dashboard provider supplied synthetic data. The actual Monarch hook
endpoint and native Claude lifecycle ran normally. The test verified:

- Context reached the model request in scope and was absent outside that scope;
  both sessions completed local model roundtrips.
- SessionEnd metadata matched the native session UUID and a nonempty transcript,
  without copying prompt text into Monarch history.
- Requests used the loopback endpoint and required user agent. Model tools and
  unrelated MCP configuration were disabled; no hosted model or financial call
  was needed.

```bash
MONARCH_CLAUDE_NATIVE_TESTS=1 \
MONARCH_CLAUDE_EXECUTABLE=/absolute/path/to/claude \
MONARCH_NATIVE_EXECUTABLE=/absolute/path/to/monarch \
uv run pytest tests/axi/test_claude_native.py -q
```

Both native tests skip ordinary gates unless opted in. The Claude runtime is a
local test prerequisite, not a new project runtime dependency or permanent install.
